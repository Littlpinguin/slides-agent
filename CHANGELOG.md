# Changelog

Earlier releases are described by their git tags (`v0.1.0` to `v0.3.0`).

## Unreleased

### Changed: a neutral default brand

- **The placeholder brand is now a neutral example palette**, the one the downstream marketing-cockpit template documents in `docs/placeholders.json`: primary `#1E40AF`, secondary `#F59E0B`, dark `#0F172A`, light `#F8FAFC`, gradient `linear-gradient(90deg, #1E40AF 0%, #F59E0B 100%)`, Inter for display and body, JetBrains Mono for labels. It replaces the identity of a real company that shipped as the default in `brand/tokens.css`, `templates/base.html`, the docs, the skills, the `scripts/pexels.py` help and the test fixtures.
- **Derived tokens follow stated formulas**, written next to each value in `brand/tokens.css` as the CSS `color-mix()` they come from (kept as literal colours, because `scripts/qa.py` and `scripts/pexels.py` read literal values): `-deep` mixes in 12% black, `-soft` is the colour at 12% alpha, `--brand-neutral-light-soft` / `-deep` mix in 35% white / 6% black, `--brand-neutral-dark-soft` / `-deep` mix in 14% white / 18% black, `--rule` / `--rule-light` are the dark / light neutral at 10% / 18% alpha. `--label-accent` stays the primary (already 7.3:1 on `--brand-neutral-light-deep`), `--label-accent-dark` is the primary mixed with 50% white (6.9:1 on `--brand-neutral-dark`, 4.6:1 on `--brand-neutral-dark-soft`). The starter passes `scripts/qa.py --with-pdf` clean with it.
- Onboarding now detects the example palette instead of the old placeholder colours; the contrast notes of `templates/components.md` no longer quote ratios of the old palette.

### Added: the slides engine of the marketing-cockpit template, upstreamed

slides-agent becomes the single source of truth of the slides engine that the marketing-cockpit template vendors. Everything generic that only the template's engine had is now here, so vendoring this repository back loses nothing.

- **Starter engine (`templates/base.html`).** Overview grouped by `data-family` (the catalogue's keys; a deck without families keeps one flat grid, an unknown family lands in "Other slides"), thumbnails as buttons with dark and tint variants, a click on the backdrop closes the panel and only `O` / `Escape` act while it is open. Folios numbered from a `SLIDE_COUNT` constant, `.nav-num` spans shipped empty. The PDF button shows an exporting state and closes the overview first; `window.__toggleFullscreen` joins the headless hooks; the progress slider is focusable with `aria-value*`. Descender-safe titles: `line-height` 1.1 on `h1.display` (and the new `h2.display`), `.gradient-text` compensation raised to `0.22em / 0.08em`. New optional `.aurora` ambient layer (rhythm slides, `z-index: -1`, QA-exempt, hidden in print), used on the breathing slide. `.slide.tint` joins `.soft` (`.cream` kept as its legacy name). Slides are their own stacking context (`isolation: isolate`).
- **Starter conventions.** The `:root` of the starter and `brand/tokens.css` keep neutral working values and name, in a comment next to each brand variable, the setup placeholder it maps to (`← BRAND_COLOR_PRIMARY`, `← BRAND_COLOR_ACCENT`, `← BRAND_COLOR_LIGHT`, `← BRAND_COLOR_DARK`, `← BRAND_GRADIENT`, `← BRAND_FONT_PRIMARY`, `← BRAND_FONT_SECONDARY`); derived values carry their `color-mix()` formula. Onboarding (`CLAUDE.md` Step 3) explains both.
- **`docs/engine-parity.md`**: the canonical list of the engine's features, mirrored by `ENGINE_MARKERS` in `scripts/qa.py`, with the parity rule and the procedure to add a feature.
- **Seven new catalogue plates (114 to 120)** for the compositions of the template that had no equivalent among the 113: `editorial-foreword`, `framed-cartouche`, `kpi-trend-cards`, `legend-table`, `chip-cloud`, `avatar-wall`, `qr-closing`. Fictional content, QA clean, indexed in `reference/LAYOUTS.md` with their family. The eighth composition, `branching-flow`, is the `y-split` skeleton (catalogue 64).
- **`templates/components.md`**: paste-ready, token-only versions of the eight compositions (with the `branching-flow` numbered-steps variant under `y-split`), the template's starter blocks (`cards`, `kpi-band`, `url-pill`), an "Ambient aurora" section, `data-family` and `SLIDE_COUNT` in "How to use", and the template's "other candidates" mapped to existing layouts. Sizes hold the type floors and small accent text takes the label-register tokens: a scratch deck built from them passes `scripts/qa.py`.
- **`tests/test_engine.py`**: the engine's behaviours in headless Chromium (folios, grouped and flat overview, keyboard and backdrop rules, PDF button state, aurora in print, descender compensation).

### Changed: `scripts/qa.py` is now a full QA gate

- **Type floors made measurable.** Content text must be at least 18px (`--min-font`, was 16px). The label register (text inside `.chrome`, the eyebrow / meta-label / signature / folio classes, and any text set in a monospace stack) has its own floor of 12px (`--min-font-chrome`) instead of being exempt. Uppercase tracked text is no longer exempt either. New warnings: `tight-body` (content under 24px) and `long-label` (a label-register text under 18px longer than 12 words).
- **New checks:** engine parity with `templates/base.html` (read from the file, `--no-engine-check` to skip, for the catalogue), brand fonts (from `--font`, a DTCG `brand/tokens.json` / `01-brand/tokens.json`, or the deck's `--font-display` / `--font-body` / `--font-mono` variables), WCAG AA contrast on every text with opacity folded in, folios present and increasing.
- **Measurement:** geometry in native frame pixels at any `--viewport` (`--frame` for another native size), slides audited in their settled state (transition delays zeroed), `.slide` and `.plate` (catalogue) detected automatically, `.slide-bg`, `[data-bleed]`, `.aurora`, `.dust-grid` and the catalogue's `.legend` skipped by every check.
- **Reporting:** stable finding ids (`overflow`, `chrome-gap`, `type-floor`, `tight-body`, `long-label`, `font`, `contrast`, `folio`, `truncated`, `lang`, `pdf-weight`), `--format json` with totals by type and a `target` per finding, per-slide cap (`--max-per-slide`), `--lang` for bilingual decks, `--screenshots [DIR]`. `--with-pdf` / `--min-kb-per-slide` are kept.
- Exit codes: 0 clean (warnings allowed), 1 errors, 2 usage error or missing Playwright.

### Added

- `tests/test_qa.py`: pure-Python tests (colour, contrast, fonts, tokens, registers, folios, cap, engine parity) and deck tests on fictional decks driven by headless Chromium, skipped when Playwright or Chromium is missing.
- **Starter clean under the new gate, plus brand-pattern hooks.** `templates/base.html` passes `scripts/qa.py` with no finding: chrome text and eyebrows reach WCAG 4.5:1 through new label-register tokens in `brand/tokens.css` (`--chrome-opacity` 0.62 to 0.7, eyebrows on `--label-accent` / `--label-accent-dark`), ledes move to 24px and the decision slide sets its values at 28px under mono labels. New optional decoration: `--brand-pattern`, `--brand-pattern-light`, `--corner-motif` and their opacities (default `none`, nothing shows), drawn by `.texture`, `.motif`, `.corner` and `.filet-orn`, and checked as an engine marker (`brand-pattern`).
- **Catalogue clean under the new gate.** All 113 plates of `reference/catalogue-layouts.html` pass `scripts/qa.py --no-engine-check` (323 errors to 0, overflow 0): content text raised to 18px the editorial way, text gold darkened to AA (`--or-text`), chrome added to plates 21-23, chrome-gap fixed on plate 88, mono family declared; pre-existing class collisions fixed on plates 31, 79 and 99.
- **PDF export and component contrast fixes.** Gradient words no longer print as a solid gradient block: the rasteriser drops the element's background for the print and now draws each character at its measured position over text left in place, so the PDF matches the screen (nested spans, collapsed spaces, letter-spacing, baseline). Light slides print on `--brand-neutral-light` instead of white (`.slide` carries a default background; the print CSS makes the frame transparent). Small accent text in `templates/components.md` moves from `--brand-primary-deep` (3.15:1) to `--label-accent` (`.process-num`, `.kanban-tag`, `.ts-label`, `.pc-link`, `.comparison-table th.c-you`, `.team-photo.initials`, `.ba .after .bt`) and small grey labels to `opacity: var(--chrome-opacity)`, so a deck built from them passes the contrast check; dark-card variants use `--brand-secondary`. New `tests/test_print.py`. See `docs/pdf-export.md`.
